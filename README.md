# The-Reapper
End game downloading tool for premium music with lrc and covers

### Prerequisites

- **Linux environment** Debian, Ubuntu, WSL
- **Root access**
- **Python 3.7+** with Flask
- **Go**
- **Git**

### Installation

1. **Clone this repository:**
   ```bash
   git clone https://github.com/Gati3000/The-Reapper.git
   ```

2. **Switch to root user:**
   ```bash
   sudo -i
   cd The-Reapper
   ```
   
3. **Run the setup:**
   ```bash
   python3 Main.py
   ```
